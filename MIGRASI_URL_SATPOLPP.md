# Persiapan perubahan alamat SIAP SATPOL PP LEMBATA

## Tujuan
Ganti repository GitHub `arywelan320-hub/siap-satpolpp-lembata` menjadi `arywelan320-hub/satpolpp`.
Alamat GitHub Pages baru setelah publikasi diverifikasi:
https://arywelan320-hub.github.io/satpolpp/

## Prasyarat
Pemilik repo melakukan rename dari GitHub:
Settings > General > Repository name > satpolpp > Rename.
Penggantian nama repository bukan penggantian identitas publik aplikasi.

## Setelah rename
1. Pastikan `arywelan320-hub/satpolpp` sudah ada dan branch main serta `backup-before-v1160` tetap tersedia.
2. Merge perubahan dari branch `persiapan-nama-satpolpp` setelah rename; jangan menerbitkan referensi URL baru sebelum situs berhasil.
3. Verifikasi status GitHub Actions deploy untuk repo baru, lalu cek URL baru, semua menu, asset dan simulasi.
4. Buat ulang QR Code yang sebelumnya menuju URL lama, kemudian perbarui poster, dokumen, dan Google Sites jika digunakan sebagai landing page.
5. Perbarui catatan URL di laporan aktualisasi.

Peringatan: GitHub tidak otomatis mengalihkan URL project GitHub Pages lama ketika repository diganti nama. Alamat lama dan QR Code lama bisa berhenti berfungsi. Jangan hapus branch backup.
Dokumentasi: https://docs.github.com/en/repositories/creating-and-managing-repositories/renaming-a-repository
